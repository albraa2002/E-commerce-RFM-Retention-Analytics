🛒 E-Commerce RFM Segmentation & Customer Retention Dashboard

📌 Project Overview
Customer retention is the ultimate growth engine for any e-commerce business. This project demonstrates a complete Data Analytics workflow to segment customers and predict churn using the **RFM (Recency, Frequency, Monetary)** model. 

By analyzing a simulated dataset of 8,000 transactions across 3,000 unique customers, this interactive dashboard identifies high-value "Champions," re-engages "At-Risk" buyers, and calculates Customer Lifetime Value (CLV) to optimize targeted marketing campaigns.

🚀 Key Business Insights & ROI
Customer Segmentation: Successfully categorized 3,000 customers into actionable cohorts (Champions, Loyal, At Risk, New, Lost) using automated quantile scoring (qcut).
  Retention Strategy: Identified that while "Champions" drive the highest Average Order Value, a significant percentage of customers fall into the "At Risk" category, highlighting an immediate opportunity for targeted discount campaigns.
  CLV Visualization: Built a dense, multi-dimensional Plotly Scatter Plot (The "Gold Standard" for RFM) mapping Recency against Frequency, with bubble sizes representing Monetary value, allowing stakeholders to visually pinpoint revenue clusters instantly.
  Executive UI/UX: Developed a premium, glassmorphism-styled interactive dashboard using pure HTML/CSS and Plotly, bypassing the need for heavy BI tools for rapid deployment.

 🛠️ Tech Stack & Methodologies
